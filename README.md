# 카톡 한눈에 5 · LockStar 잠금화면 호환 개선

개인용 카카오톡 알림 확인 Android 앱. 카카오 공식 앱이 아닙니다.

## 기능
- 앱에서 표시할 채팅방 수를 **1~4개 중 선택**해 2×1 홈 화면 및 Good Lock LockStar 위젯에서 확인
- 현재 시스템 카톡 알림의 추정 개수와 마지막으로 감지된 알림 시간 표시
- **위젯 글씨 정렬**: 왼쪽 / 가운데 / 오른쪽
- **둥근 모서리 안쪽 안전 여백**: 10dp / 14dp(기본) / 18dp
- 선택한 줄 수(1~4)에 맞추어 행을 자동 배치하고, 작은 잠금화면 위젯에서는 **글꼴 크기 자동 축소**
- 긴 톡방 이름은 마지막 알림 개수·시간을 우선하도록 줄임표로 처리
- 위젯 배경 테마(다크/화이트/반투명)와 글꼴 크기(3단계)
- 알림 접근 권한 기반 감지, 연결 복구 요청, 수동 새로고침, 재부팅 후 재등록, 간헐적 상태 점검
- 방해금지 모드 유지 가능, 인터넷 권한 없음, 메시지 본문 저장 없음

## 설치
Actions → Build Android APK → 최신 성공 작업 → Artifacts → kakaofocus-debug-apk (압축 해제 후 APK 설치).
이번 빌드는 `com.kyubang.kakaofocus5`이므로 기존 1~3 버전과 **별도 설치**됩니다.

## 사용법
1. 카카오톡 알림 활성화 → 새 앱에서 알림 접근 권한 허용
2. 앱에서 표시할 톡방 개수를 1~4개 중 선택한 다음 이름을 등록해 저장
3. '위젯 디자인'에서 **글씨 정렬**, **모서리 여백** 설정 후 '적용'
4. 홈 화면 또는 Good Lock → LockStar에서 **카톡 한눈에 5** 위젯을 추가
5. LockStar에서 위젯 자체의 크기를 너무 작게 줄이면 특히 4줄을 보장할 수 없습니다. 모서리에 글씨가 걸릴 경우 안전 여백 '넓게', 글씨 '작게'로 조절하세요.

## 주의점
- Good Lock LockStar의 위젯 프레임 및 재단 규칙은 버전·기기에 따라 달라져 모든 화면에서 잘림을 100% 없앤다고 보장할 수 없습니다.
- 위젯 수치(×N)는 카카오톡의 실제 미확인 메시지 수가 아니라 현재 안드로이드 알림의 추정량입니다.
- 카카오톡 알림에 채팅방 이름이 없거나 알림이 숨겨지면 감지가 제한됩니다.
- 재연결 점검은 Android의 절전/Doze 제한으로 지연될 수 있습니다.
- 앱 알림 접근 권한 자체는 모든 앱 알림을 읽는 수준이지만 코드에서는 카카오톡 알림만 사용하며 외부 서버 전송이 없습니다.
