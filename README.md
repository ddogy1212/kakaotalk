# 카톡 한눈에 정식 · v2.6 — 단톡방 알림 감지 개선

## v2.6 핵심 변경
- 카카오톡이 단톡방 이름을 일반 제목에 넣지 않는 경우를 대비해 Android MessagingStyle의 대화 이름, 숨겨진 대화 이름, 알림 대화 ShortcutInfo의 표시 이름도 확인합니다.
- 앱이 식별 가능한 개별 대화 알림은 **메시지 내용이나 원본 식별자를 저장하지 않고**, 기기 내 무작위 솔트를 적용한 해시 식별자만 최근 7일/최대 16개 기록합니다.
- **톡방 관리 → 최근 카톡 알림을 톡방에 연결** 버튼을 추가했습니다. 단톡방 메시지 알림을 받은 직후 해당 알림의 시각과 표시 후보를 보고 원하는 등록 톡방에 연결하세요.
- 알림이 방 이름을 제공하지 않아도 연결된 동일 대화 식별자로 수신 알림을 분류할 수 있습니다. 톡방 이름을 통한 기존 자동 감지도 그대로 유지합니다.
- **연결된 알림 해제** 버튼과 톡방 카드의 연결 상태, 알림 진단 상세(권한/연결/최근 대화/매칭 방식)를 추가했습니다.
- 각 알림 처리를 개별 예외 보호하여 일부 카톡 알림이 비정상이어도 모든 알림 감지가 멈추지 않도록 개선했습니다.
- **제한**: 카카오톡이 대화 식별자를 전혀 제공하지 않는 경우 직접 연결도 불가능합니다. 최근 알림에 `방 이름 미제공`이 나타날 수 있고, 알림 메시지 수는 실제 읽지 않은 채팅 수와 다를 수 있습니다. 카카오톡 업데이트로 식별자가 바뀌면 재연결이 필요합니다. 메시지 본문은 읽거나 저장하지 않습니다.
- 기존 앱 ID `com.kyubang.kakaofocus.stable`과 서명키를 유지한 **versionCode 16 / v2.6** 정식 업데이트입니다. 기존 앱을 삭제하지 마세요.

### 직접 연결 방법
1. 정식 v2.6을 기존 앱 위에 설치한 후, **톡방 관리에서 감지할 톡방 이름을 등록하고 저장**합니다.
2. 카카오톡의 해당 단톡방에서 **새 알림을 한 번 수신**합니다.
3. 앱의 **최근 카톡 알림을 톡방에 연결**을 누르고, 방금 도착한 알림을 시각으로 구분해 선택합니다.
4. 어느 등록 톡방에 연결할지 선택합니다. 바로 현재 표시가 갱신됩니다.
5. 새 알림을 받은 후 해당 톡방의 x0가 변하는지 확인합니다.

# 이전 업데이트 v2.4

## v2.4 디자인 편집 개선
- ‘위젯 꾸미기’에서 **2×1 톡방 글씨(7~18sp)**, **1×1 글씨(6~16sp)**, **수능 D-day 글씨(4~12sp)** 크기를 각각 슬라이더로 조절합니다.
- **둥근 모서리 안전 여백(6~26dp)**, **D-day 위쪽 여백(2~30dp)**, **D-day 오른쪽 여백(2~32dp)**도 슬라이더로 조절합니다.
- 테마(다크·화이트·반투명), 왼쪽·가운데·오른쪽 정렬도 **선택하는 즉시 앱 내부 미리보기만 변경**됩니다.
- 2×1과 1×1 미리보기를 모두 제공하며, 디자인 변경 중에는 기존 실제 위젯 설정을 건드리지 않습니다.
- **‘✓ 이 디자인 적용’ 버튼을 한 번 눌러야** 새로운 설정을 저장하고 실제 위젯을 업데이트합니다.
- 새 백업 ZIP(schema 3)은 글씨 크기·여백을 보관하고 기존 schema 1/2 ZIP도 복원할 수 있습니다.
- **같은 고정 applicationId, 같은 영구 서명키, versionCode 14**를 사용하므로 정식판 v2.0~v2.3 설치 위에 덮어쓰기 업데이트가 가능합니다.
- LockStar에서 매우 작은 크기로 위젯을 자르는 경우 텍스트 잘림 가능성은 남아 있습니다. 특히 4개 톡방을 큰 글씨로 설정하면 공간이 부족할 수 있습니다.

# 이전 업데이트 v2.3

## v2.3 업데이트
- 2×1 알림 위젯의 수능 D-day를 둥근 오른쪽 위 모서리로부터 **아래쪽 9dp, 안쪽 12dp** 더 이동했습니다. 기존 위젯의 가변 안전 여백(10/14/18dp)도 그대로 적용됩니다.

- 톡방 정렬, 별명 설정, 알림 감지, 차단 위젯, 백업/복원 설정은 모두 유지합니다.
- 기존 정식판과 **동일한 앱 ID와 서명키**를 사용하며 versionCode **13**, versionName **2.3**이므로 앱 삭제 없이 업데이트 설치가 가능합니다.
- Good Lock 자체가 위젯에 추가 마스크를 적용하는 일부 화면은 완전한 잘림 방지가 보장되지 않을 수 있습니다.

# 이전 업데이트 v2.2

## 이번 업데이트 (기존 정식 앱에 덮어쓰기 설치)
- **톡방별 위젯 표시 별명(선택):** 톡방 관리 탭에서 '감지용 실제 이름' 아래 짧은 '위젯 표시용 별명'을 입력할 수 있습니다. 이름을 등록한 방만 선택적으로 별명을 사용하며, 비우면 실제 이름을 표시합니다.
- 알림 인식/단톡방 구분은 기존 **실제 이름**으로만 수행합니다. 별명은 2×1 위젯, 1×1 알림 위젯, 앱 미리보기의 표시 글자에만 영향을 줍니다.
- **집중 차단 시간 슬라이더 수정:** 움직일 수 있는 바의 왼쪽(1분)과 오른쪽(60분) 끝에 각각 끝값을 고정했고, 기존 청록색 바·손잡이는 앱의 핑크 색상으로 통일했습니다. 바를 움직이고 놓으면 시간 설정이 저장됩니다.
- 상태 표시 글씨와 버튼·톡방 설정의 시각적 스타일을 통일하고, 원래 톡방 이름과 별명 입력을 분리한 톡방별 입력 카드로 개선했습니다.
- **설정 백업에 별명 포함:** 새로 내보내는 ZIP은 schema 2(별명 포함)입니다. 이전 schema 1 ZIP도 복원 가능하며 그 경우 별명은 공란으로 복원됩니다.
- 정식판 앱 ID `com.kyubang.kakaofocus.stable` 및 영구 서명 인증서를 유지하고 **versionCode 12 / v2.2**로 올려, 기존 정식판 2.0·2.1 위에 업데이트할 수 있습니다. 기존 앱 삭제 불필요.
- 설치 후 톡방 관리에서 필요한 별명을 입력하고 **'톡방 설정 저장'**을 누르면 모든 위젯에 표시됩니다.

# 이전 업데이트 v2.1

## v2.1: Good Lock 잠금화면 정렬·반투명 테두리 수정

- 2×1 위젯: 톡방 줄을 각각 어긋나게 가운데 정렬하던 원인이었던 첫 번째 줄 전용 오른쪽 여백을 제거했습니다.
- 1~4개 톡방 줄을 **하나의 그룹으로** 배치하고, 그룹과 개별 줄 모두 왼쪽·가운데·오른쪽 정렬 설정을 적용하도록 변경했습니다.

- 반투명 테마의 1dp 밝은 테두리(stroke)를 완전히 삭제했습니다.
- **기존 정식판 v2.0과 같은 applicationId·서명키**, versionCode 11로 빌드하므로 삭제 없이 업데이트 설치할 수 있습니다.
- Good Lock 또는 삼성 런처 자체가 그리는 외곽선은 앱에서 제거할 수 없으므로 실제 잠금화면에서 확인이 필요합니다.

# v1.8 기능 (정식판에도 유지)

개인용 Android 위젯 앱입니다. 카카오톡 공식 앱은 아닙니다.

## 이번에 추가된 기능

### 1×1 사진형 카톡 차단 위젯의 표시 방식
'집중 차단' 탭에서 다음 세 가지를 선택해 저장할 수 있습니다.
- **자세히:** '카톡 차단 중' + 큰 남은 시간 + 자동 해제 문구 (기존 방식)
- **간단히:** 사진 위에 작은 **9sp 남은 시간**만 표시
- **사진만:** 차단 중에도 **사진만** 표시하며 남은 시간은 감춤

사진이 없으면 상태를 확인할 수 있도록 기존 글씨가 표시됩니다. 차단 시간은 1~60분 슬라이더로 설정하며 기본은 10분입니다. 남은 시간은 앱 '집중 차단' 탭에서도 확인할 수 있습니다.

### 오프라인 설정 백업 및 복원
'위젯 꾸미기 → 설정 백업·복원'에서 **ZIP 파일 내보내기/불러오기**:
- 선택 톡방 수(1~4개)와 등록된 톡방 이름
- 위젯 테마·글자 크기·정렬·안전 여백
- 차단 시간과 사진 위 표시 방식
- 편집해 적용한 **1×1 차단 위젯 사진**

백업에 채팅 본문, 알림 기록, 실제 알림 수, 진행 중인 차단 상태, 보안 권한은 포함되지 않습니다. **알림 접근 및 접근성 권한은 직접 다시 허용**해야 합니다. 백업 파일에 톡방 이름과 선택한 사진이 포함되므로 다른 사람과 공유하지 마세요.

복원은 사용자가 Android 파일 선택기에서 ZIP 파일을 지정하고 확인한 뒤에만 현재 설정을 덮어씁니다. 파일 내용 검증과 크기 제한을 적용합니다.

## 기존 기능 유지
- 2×1 알림 위젯: 톡방 알림의 추정 개수/시간, 오른쪽 상단 작은 **2027-11-18 수능 D-day**
- 1×1 알림 위젯: 작은 텍스트 알림 확인
- 1×1 사진형 차단 위젯: 사용자가 고른 사진을 누르면 지정한 시간 동안 카톡 진입 시 홈 화면으로 이동시키는 접근성 기반 자기관리 기능
- 갤러리에서 사진 선택 후 드래그/확대/회전/영역 선택 및 자르기
- 3개 앱 탭: 톡방 관리 / 위젯 꾸미기 / 집중 차단
- 단체채팅 알림 제목 진단

## 설치
GitHub Actions → 최신 성공한 'Build Android APK' → Artifacts 'kakaofocus-debug-apk' 압축 해제 후 APK 설치.

v1.8은 `com.kyubang.kakaofocus9`으로 기존 v1.7(`com.kyubang.kakaofocus8`)과 **별개 앱**입니다. 현재 v1.7에는 백업 내보내기 기능이 없으므로 **기존 v1.7의 설정을 파일로 직접 추출하거나 v1.8로 자동 복사할 수는 없습니다**. v1.8에서 한 번 설정한 뒤 백업 파일을 만들어두면 새 버전에서도 가져오도록 설계했습니다.

APK는 개발용 임시 서명으로 빌드됩니다. 같은 패키지의 다른 빌드에서 서명이 달라질 수 있으므로 영구 서명키를 구성하기 전에는 **덮어쓰기 업데이트가 보장되지 않습니다**.

## 기술적 제한
- 알림 개수는 Android의 알림을 바탕으로 추정합니다. 카카오톡의 실제 미확인 메시지 수와 다릅니다.
- 단톡방 이름이 Android 알림에 제공되지 않으면 구분할 수 없습니다.
- 접근성 권한을 켠 경우에만 카톡 전면 실행 시 홈 화면으로 돌아가게 하며, 시스템 수준의 완전한 차단은 아닙니다.
- Good Lock LockStar가 위젯을 작게 잘라 표시하면 일부 글씨가 가려질 수 있습니다.
- 수능 D-day는 대한민국 시간대 기준으로 계산하고 Android의 절전 정책으로 표시 갱신이 지연될 수 있습니다.
