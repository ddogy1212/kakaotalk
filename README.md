# 카톡 한눈에 3 · 2×1 카카오톡 알림 위젯

**개인용 안드로이드 앱**으로, 카카오톡을 열지 않고 등록한 톡방 최대 3곳의 알림을 작은 2×1 위젯에서 확인합니다. 공식 카카오톡 앱이 아닙니다.

## 기능
- 앱 안에서 **채팅방 이름 최대 3개 등록** 또는 감지된 최근 알림 제목에서 선택
- 2×1 위젯에 세 줄 표시: `학급방  ×3 · 21:42`
- **마지막 수신 시간** 표시: 오늘이면 HH:mm, 이전 날짜면 M/d. 알림이 지워져도 마지막 확인 시각은 남습니다.
- **위젯 디자인**: 다크, 화이트, 반투명 / 글자 크기 작게·보통·크게
- **알림 연결 복구 강화**: 재연결 요청, 수동 새로고침, 재부팅 후 건강 상태 확인, 위젯이 있을 때 배터리 절약형 비정확 30분 간격 점검. 휴대폰의 절전 제한으로 점검이 지연되거나 불허될 수 있습니다.
- DND(방해금지 모드)를 해제하지 않으며 메시지 본문은 저장하지 않습니다. 앱에 인터넷 권한이 없습니다.

## 설치
GitHub **Actions → Build Android APK → 최신 성공 작업 → Artifacts → kakaofocus-debug-apk**를 다운로드, ZIP을 풀어 APK를 설치합니다.

이 버전의 Android applicationId는 `com.kyubang.kakaofocus3`입니다. 기존의 카톡 한눈에 2(`com.kyubang.kakaofocus2`)와 **별도 앱**으로 설치되어 기존 앱 삭제 없이 사용할 수 있습니다. 앱을 처음 열어 알림 접근 권한 및 톡방 설정을 새로 해야 합니다.

## 사용
1. 카카오톡 알림은 켜두고 방해금지 모드는 유지해도 됩니다.
2. 카톡 한눈에 3 → 알림 접근 권한 허용
3. 앱에서 톡방 최대 3개 선택/입력 후 저장
4. 앱의 위젯 디자인에서 원하는 테마와 크기 선택 후 **위젯 디자인 적용**
5. 홈 화면에서 **카톡 한눈에 3 → 2×1 위젯** 추가
6. 감지 오류 시 앱에서 연결 확인·새로고침 및 삼성 배터리 사용 '제한 없음' 확인

## 정확도 및 개인정보
- `×N`은 **현재 시스템에서 확인 가능한 알림의 추정 개수**이며 카카오톡 내부의 실제 안 읽은 메시지 개수와 다릅니다.
- 대화명이 알림에 노출되지 않거나 알림이 제거되면 카운트가 0 또는 감지 불가로 나타날 수 있습니다.
- 마지막 수신 시간은 수신한 알림 타임스탬프를 저장한 것이며 실제 카톡 대화의 최종 시각과 다를 수 있습니다.
- 알림 접근 권한은 다른 앱 알림도 읽을 수 있는 강한 권한이지만 이 앱의 코드는 **카카오톡 알림만 처리**합니다. 톡방 이름과 추정 수, 마지막 시각을 로컬에 보관하며 외부 전송 기능은 없습니다.
- 건강 상태 점검은 배터리 최적화/Doze 등에 의해 지연될 수 있으며 완전한 실시간 보장을 제공하지 않습니다.
