# 카톡 한눈에 6 (v1.5)

카카오톡을 열지 않고 지정한 톡방 1~4개의 **시스템 알림**만 2×1 홈 화면 / Good Lock LockStar 위젯에 표시하는 개인용 안드로이드 앱입니다. 공식 카카오톡 앱이 아닙니다.

## v1.5 개선
- **세로 간격 수정:** 각 줄을 위젯 높이만큼 벌리지 않고 가운데에 가까이 배치합니다. 줄 사이에 아주 작은 여백만 둡니다.
- **가로 공백 축소:** 방 이름과 ‘×N · HH:mm’ 사이의 불필요한 공백을 줄였습니다.
- **단톡방 감지 보강:** 안드로이드 알림의 대화 제목, 보조 제목, 일반 제목, 큰 제목, 요약 제목 등 여러 메타데이터를 확인합니다. 일부 카톡 버전에서 단체 알림이 요약으로 도착할 때도 가능한 방 이름과 비교합니다.
- **단톡방 감지 진단:** 앱 안에서 ‘단톡방 감지 정보 확인’을 눌러 실제 알림에 제공된 대화명/보조제목/제목을 볼 수 있습니다. 메시지 본문은 표시하거나 저장하지 않습니다.
- 알림에 단톡방 이름이 **아예 제공되지 않으면** 특정 방으로 확실하게 식별할 수 없습니다. 모든 카톡 버전에서 단체방 감지가 보장되는 것은 아닙니다.
- 톡방 개수 1~4개, 글씨 정렬(왼쪽/가운데/오른쪽), 둥근 모서리 여백(10/14/18dp), 다크/화이트/반투명, 글자 크기 설정 유지
- 방해금지 모드 유지 가능, 알림 연결 재시도 및 주기적 점검 (절전 정책으로 지연 가능)

## 설치
1. GitHub Actions > Build Android APK > 최신 성공한 작업 > Artifacts > `kakaofocus-debug-apk`를 받습니다.
2. ZIP을 풀고 `app-debug.apk`를 설치합니다.
3. 앱 이름은 **카톡 한눈에 6**, 패키지 이름은 `com.kyubang.kakaofocus6`입니다. 이전 앱은 지우지 않아도 별도로 설치됩니다.
4. 알림 접근 권한을 허용하고 톡방 이름을 1~4개 등록한 뒤 홈 화면 또는 LockStar에서 위젯을 추가합니다.
5. 단톡방에서 메시지가 와도 표시되지 않는다면 ‘단톡방 감지 정보 확인’에서 알림에 적힌 이름 후보를 확인합니다.

## 유의사항
- **×N**은 카카오톡의 실제 읽지 않은 대화 개수가 아닌 현재 안드로이드 알림에서 추정한 수입니다. 알림을 지우면 0으로 돌아올 수 있습니다.
- 저장하는 내용은 선택한 방 이름, 감지된 알림 제목·보조제목·대화명 진단값, 추정 수, 마지막 감지 시각입니다. **메시지 본문이나 원문 대화는 저장하거나 서버로 보내지 않습니다.** 인터넷 권한이 없습니다.
- 앱의 알림 접근 권한은 시스템상 넓은 권한이므로 개인 기기에서만, 코드를 신뢰하는 경우에 허용하세요.
- LockStar 자체가 매우 작은 영역을 주거나 위젯을 잘라내는 경우 완전한 레이아웃 표시를 보장할 수 없습니다.
