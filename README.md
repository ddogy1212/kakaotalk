# 카톡 한눈에 8 · v1.7

카카오톡 알림을 간단히 확인하고, 원하는 시간 동안 앱 사용을 스스로 제한하는 **개인용 Android 위젯 앱**입니다. 카카오톡 공식 앱이 아닙니다.

## 이번 버전에서 바뀐 점
- **수능 D-day를 2×1 위젯의 실제 오른쪽 위 모서리에 별도 오버레이**로 배치했습니다. 5.5sp로 기존 톡방 글씨(상황별 약 7.5~11sp)보다 작습니다. 날짜는 2027-11-18(2028학년도 수능)이며 한국시간 기준으로 갱신합니다.
- **위젯 사진 설정은 단 하나**: 이제 **1×1 카톡 차단 위젯에서만** 사진을 사용합니다. **1×1 알림 위젯은 기존처럼 글씨로만** 알림을 보여줍니다.
- **갤러리 사진 선택**: Android 13 이상에서는 시스템 사진 선택기, 이전 버전에서는 이미지 선택 창을 사용합니다.
- **내장 사진 편집기**: 사진 드래그로 이동, 두 손가락 확대·축소, 정사각형 선택 테두리 드래그로 영역 이동, 네 모서리 잡아 선택 크기 조절, 90° 회전 버튼, -180°~180° 임의 각도 회전 슬라이더, 전체 초기화. 적용한 정사각형 결과물(384×384)을 위젯 사진으로 사용합니다.
- 사진은 디바이스 내부 저장소에만 보관하며 인터넷 업로드나 메시지 읽기 기능이 없습니다.

## 제공 위젯
| 크기 | 종류 | 기능 |
|---|---|---|
| 2×1 | 카톡 알림 | 등록 톡방 1~4개, 현재 알림의 추정 수, 마지막 시각, 오른쪽 위 수능 D-day |
| 1×1 | 카톡 알림 | 동일한 등록 톡방의 알림을 작은 텍스트로 표시. 사진 선택 없음 |
| 1×1 | 사진형 집중 차단 | 선택한 **한 장의 사진**을 표시하고, 탭하면 1~60분 동안 카톡 화면에 진입할 때 홈으로 이동시킴 |

## 사용 방법
1. 설치 후 카카오톡 알림 접근 권한을 직접 허용하고, 톡방 1~4개를 등록합니다.
2. **위젯 꾸미기**에서는 공통 위젯 스타일만 지정합니다. (다크/화이트/반투명, 글자 크기, 정렬, 모서리 안전 여백)
3. **집중 차단 → 갤러리에서 사진 선택 · 편집**을 누릅니다.
4. 사진 편집 화면에서 자를 정사각형의 위치와 크기를 드래그/조절하고 확대·축소 및 회전한 뒤 **이 영역으로 적용**을 누릅니다.
5. **집중 차단** 탭의 슬라이더에서 1~60분을 설정합니다(기본 10분).
6. 위젯 1×1 사진형 차단을 추가하고, 시스템 접근성 설정에서 **카톡 시간 제한** 서비스를 직접 켭니다. 차단은 시스템 완전 잠금이 아니고 접근성 서비스가 카톡이 열리는 것을 감지한 후 홈으로 보내는 방식입니다.

## 설치
[GitHub Actions](https://github.com/ddogy1212/kakaotalk/actions) → 최신 **Build Android APK** 성공 작업 → `kakaofocus-debug-apk` 아티팩트 다운로드 → ZIP 압축 해제 후 APK 설치.

새 패키지 `com.kyubang.kakaofocus8`로 기존 카톡 한눈에 1~7과 별도로 설치됩니다. 톡방/알림 권한/차단 서비스 설정은 새로 해야 합니다.

## 한계
- 알림 수는 Android 시스템에 표시된 알림을 기반으로 추정하므로 카톡의 진짜 읽지 않은 메시지 개수와 다를 수 있습니다.
- 단톡방명이 카카오톡 알림에 제공되지 않으면 해당 방을 감지할 수 없습니다.
- 굿락의 LockStar 또는 런처가 위젯을 너무 작게 자르는 경우 D-day와 글씨가 일부 잘릴 수 있습니다.
- 이미지를 회전해 잘라낼 때 사진 가장자리를 벗어난 부분은 어둡게 출력될 수 있으니 편집 화면에서 확인하세요.
- 접근성 기반 차단은 시스템 정책 및 권한 설정의 영향을 받으며 완벽한 차단을 보장하지 않습니다.
