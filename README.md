# 카톡 한눈에 (Kakao Focus)

선택한 카카오톡 채팅방 세 개의 **현재 표시 중인 알림**만 2×1 홈 화면 위젯으로 보여주는 Android 앱입니다.

- 방별 `채팅방에서 알림 ×N` / `알림 없음` 표시
- 메시지 내용은 저장하거나 위젯에 노출하지 않음
- 방해금지 모드를 변경하지 않고 알림 접근 권한으로 동작
- **카카오톡 앱과 독립적인 개인 프로젝트**이며 카카오 공식 앱이 아닙니다.

## 설치
GitHub Actions > Build Android APK > 최신 성공 작업 > Artifacts에서 `kakaofocus-debug-apk` 다운로드, 압축 해제한 APK 설치.

## 최초 설정
1. 카카오톡 앱의 알림은 켜둡니다. 방해금지 모드는 유지해도 됩니다.
2. 이 앱의 '알림 접근 설정'에서 접근 권한을 허용합니다. 모든 알림을 읽을 수 있는 권한이므로 코드를 신뢰하는 경우에만 허용하세요.
3. 앱에서 채팅방 이름 3개를 실제 알림에 표시되는 이름 그대로 입력하고 저장합니다.
4. 홈 화면 > 위젯 > 카톡 한눈에 > 2×1 배치.

## 중요한 한계
- 위젯 수치는 **현재 안드로이드에 남아 있는 알림의 대략적 메시지 개수**입니다. 카카오톡의 실제 읽지 않은 메시지 개수와 다를 수 있습니다.
- 사용자가 알림을 지우거나 휴대폰/카카오톡이 알림을 숨기면 감지할 수 없습니다.
- 그룹방 알림에서 방 이름이 제공되지 않으면 해당 방을 정확히 구분할 수 없습니다.
- 메시지는 기기에만 처리하며 인터넷 권한이나 외부 전송 기능은 없습니다.
