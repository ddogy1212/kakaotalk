# 카톡 한눈에 7 · v1.6

개인용 Android 위젯 앱입니다. 카카오톡 공식 서비스가 아닙니다.

## 위젯 세 종류
1. **2×1 카톡 알림:** 사용자가 등록한 톡방 1~4개, 현재 Android 알림 개수(추정), 마지막 알림 시간, 구석에 **수능 D-day**를 표시. 시험일은 교육부 발표대로 **2027-11-18(2028학년도 수능)** 입니다. 대한민국 서울 시간 기준 날짜 변경에 따라 갱신합니다.
2. **1×1 카톡 알림:** 등록 톡방의 알림을 아주 좁은 크기로 표시하며 **사진 배경을 앱에서 따로 선택**할 수 있습니다. 1~2개 방은 시간도 표시하며 3~4개 방은 공간을 아끼기 위해 시간은 생략합니다.
3. **1×1 사진형 카톡 제한:** 앱에서 선택한 사진만 보이는 위젯입니다. 사진을 누르면 설정한 **1~60분** 동안 카카오톡 실행 시 홈 화면으로 되돌립니다. 기본값은 **10분**, 남은 시간은 제한 중 사진 위에 표시됩니다.

## 앱 사용
앱은 세 탭으로 구성됩니다:
- **톡방 관리:** 1~4개 등록/선택, 알림 접근 권한, 단톡방 감지 정보 진단
- **위젯 꾸미기:** 다크·화이트·반투명, 글자 크기, 정렬, 모서리 여백, **1×1 알림 위젯 사진 선택**
- **집중 차단:** 1~60분 슬라이더, **1×1 차단 위젯 사진 선택**, 접근성 설정

사진은 Android 사진 선택 창으로 고릅니다. 가로/세로 비율과 무관하게 축소하여 **앱의 내부 저장소에만 저장**하며 외부 서버로 전송하지 않습니다. 저장 사진은 앱에서 삭제/교체 가능합니다. 인터넷 접근 권한을 요구하지 않습니다.

## 제한 기능의 권한 및 동작
- 다른 앱을 제어하는 기능은 Android의 **접근성 서비스** 권한이 필요합니다. 사용자가 직접 활성화해야 하며, 기기에 따라 사이드로드 앱에서 **제한된 설정** 해제를 요구할 수 있습니다.
- 서비스는 카카오톡 패키지의 창 변경 이벤트만 확인하도록 설정되어 있으며 메시지 내용이나 화면 요소를 읽지 않습니다.
- 제한은 카카오톡 앱 실행을 감지한 뒤 홈 화면으로 이동시키는 **앱 수준의 자기관리 기능**으로, 잠깐 화면이 보이거나 시스템 정책으로 동작하지 않을 수 있습니다. 권한을 해제하거나 강제 종료하면 제한을 우회할 수 있으므로 완전한 잠금은 보장되지 않습니다.
- 제한 중 다시 위젯을 눌러도 시간을 연장하지 않습니다. 시스템 시간을 임의로 바꾸면 남은 시간에 영향을 줄 수 있습니다.
- 만료 시 앱 내부에서 자동으로 제한이 풀립니다. 홈 화면 위젯의 남은 시간 표시 갱신은 Android 배터리 제어에 의해 늦어질 수 있습니다.

## 설치
[GitHub Actions](https://github.com/ddogy1212/kakaotalk/actions) → 최신 **Build Android APK** 성공 빌드 → Artifacts → `kakaofocus-debug-apk` ZIP 다운로드 → 압축 해제 후 `app-debug.apk` 설치.

패키지 이름은 `com.kyubang.kakaofocus7`이며 기존 1~6 앱과 **별도로 설치**되므로 기존 앱을 제거할 필요가 없습니다. 새 앱에서는 톡방/권한/위젯을 다시 설정해야 합니다.

## 정확도
- 카톡의 실제 안 읽은 메시지 수가 아닌 **Android 시스템에서 감지한 알림 추정 수**입니다.
- 단체 톡방 이름이 알림 메타데이터에 없으면 감지할 수 없습니다.
- Good Lock LockStar의 작은 크기는 글자가 잘릴 수 있으며 테마, 글자 크기, 여백을 조절할 수 있습니다.
- Android 배터리 절약 정책이나 방해금지 설정에 따라 알림 감지 및 주기적 갱신이 제한될 수 있습니다.
